# توليد نسخ القراءة

نسخ Markdown داخل `docs` هي مصدر المحتوى، وملفات HTML المرفقة قابلة للقراءة دون تثبيت أي أدوات.

لتجديد HTML بعد تعديل النصوص، من هذا المجلد وباستخدام Node.js 22.16 أو أحدث:

```sh
npm install
npm run build
```

يعيد الأمر توليد وثيقة المنتج ووثيقة تخطيط البيانات وملف تسليم الفريق. لتوليد ملف التسليم وحده: `node build-brief.mjs handoff`. لا تتصل أداة التوليد بخدمة خارجية؛ تثبيت المكتبة فقط يحتاج الاتصال بسجل npm. يُستخدم إصدار محدد من مكتبة marked. هذه أداة للوثائق، وليست تهيئة لتطبيق Crow Station.
